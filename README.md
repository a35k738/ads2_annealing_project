# Отжиг и эвристические алгоритмы

Три оптимизационные задачи: A — мультипликативный рюкзак, B — курьер и районы города, C — сбор заказов к концу смены.

## Что здесь лежит

- `annealing_contest_tasks.pdf` — описание работы: правила, баллы, сдача, устройство отчёта, критерии оценки и условия задач с материалами и вопросами для отчёта. Начните с него.
- `annealing_contest_tasks.tex` — исходник того же PDF.
- `practice/` — открытые данные для экспериментов:
  - `A/`, `B/`, `C/` — по три тренировочных теста: вход `.in`, допустимый ответ организаторов `.out` и его качество `.ref`;
  - `samples/` — примеры из условий;
  - `evaluate.py` — локальная проверка допустимости ответа, качества $Q$ и балла за тест;
  - `README.md` — как запускать проверку и как устроены тренировочные данные.

## Как сдавать

1. Решения отправляйте в Яндекс.Контест. Отправьте туда и базовую, и итоговую версии каждой задачи.
2. До **23:59 26 октября** заполните [форму сдачи](https://forms.gle/TDwSiA4uJwitTx228): ФИО, группа, логин в Контесте, отчёт в PDF и лог общения с ИИ.

Подробности — в разделах «Сдача работы» и «Отчёт» в PDF.

## Быстрый старт

```bash
cd practice
python3 your_solution.py < A/01.in > answer.txt
python3 evaluate.py A A/01.in answer.txt --reference A/01.ref
```

Нужен Python 3.11 или новее, сторонние библиотеки не требуются.
