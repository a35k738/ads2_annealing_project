# Открытые данные для экспериментов

В папках `A`, `B`, `C` находятся по три тренировочных теста. Для каждого есть вход `.in`, допустимый авторский ответ `.out` и его качество `.ref`. Это ориентиры для сравнения, а не доказанные оптимумы. В папке `samples` находятся по два маленьких примера каждой задачи.

Полный текст заданий лежит в корне репозитория: `annealing_contest_tasks.pdf` (исходник — `annealing_contest_tasks.tex`). Сначала прочитайте общие правила в его начале, затем условие выбранной задачи. В PDF описаны понятия для изучения, литература, эксперименты, устройство отчёта и вопросы для него. В самом Контесте приведено только формальное условие.

## Запуск и проверка

Например, из этой папки:

```bash
python3 solution.py < B/01.in > answer.txt
python3 evaluate.py B B/01.in answer.txt --reference B/01.ref
```

На Windows можно выполнить команды с перенаправлением в `cmd`. Вместо `solution.py` укажите свою программу. Для C++ сначала скомпилируйте её, затем перенаправьте вход и вывод аналогичным образом.

Локальная проверка требует только стандартную библиотеку Python 3.11 или новее. Без `--reference` она выводит допустимость и качество; с этим параметром — ещё и балл одного теста. В задаче A качество — сумма натуральных логарифмов множителей; в B — длина цикла; в C — максимальное время сотрудника. Именно эти числа следует использовать в таблице экспериментов.

Числа в локальной проверке вычисляются в `double`, в серверном чекере — в `long double` (для A и B). Возможны несущественные отличия последних знаков. Пустой набор в A допустим и получает нулевое качество.

Наборы данных: A — ловушка для жадного выбора, смешанные множители, зависимые стоимости и полезности; B — компактные кластеры, разная плотность, равномерные точки; C — значительные времена сборки, складские проходы, удалённые задания. Параметры закрытых тестов отличаются, но постановка остаётся той же.

Сравните базовую и изменённую версии на двух-трёх тестах при одинаковом времени. Для случайного метода используйте минимум три заранее выбранных seed. Сохраните качество, время, источник идеи и вывод — всё это войдёт в таблицу эксперимента в отчёте.
